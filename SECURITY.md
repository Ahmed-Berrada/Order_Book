# Security policy

This is a reference implementation of a trading venue, not a production service, and it has not been
audited. Report a vulnerability privately through GitHub's *Report a vulnerability* (Security tab of the
repository). Please do not open a public issue for one. Expect an acknowledgement within a few days; there is
no bug bounty.

What is in scope and how the project thinks about it: [`docs/security/threat-model.md`](docs/security/threat-model.md).
Supply chain controls (CodeQL, dependency review, Dependabot, SBOM, signed release provenance) are in
[`docs/security/supply-chain.md`](docs/security/supply-chain.md).
